# Research

My research interests focus on applying **Machine Learning and Data Science to real-world problems**, with particular interest in healthcare analytics and predictive modeling.

## Current Research

### Postpartum Mental Health Classification Using Machine Learning

A machine learning-based multiclass classification study focusing on postpartum mental health conditions.

The research explores the application of machine learning techniques to classify different postpartum mental health categories using demographic and symptom-related features.

### Research Focus

- Multiclass classification
- Machine Learning
- Healthcare Data Analytics
- Predictive Modeling
- Feature-based classification
- Model evaluation
- Imbalanced data handling

### Machine Learning Approaches

The research explores several machine learning approaches, including:

- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Random Forest
- XGBoost
- Stacking Ensemble Learning

## Previous Research Interest

### PCOS Risk Prediction

A machine learning-based project focused on predicting high-risk age groups associated with Polycystic Ovary Syndrome (PCOS).

The project explores the use of demographic and health-related attributes for predictive analysis using machine learning techniques.
