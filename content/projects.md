# Projects

## Postpartum Mental Health Classification

### Overview

A machine learning project focused on multiclass classification of postpartum mental health conditions.

### Objective

To explore whether machine learning can be used to classify different postpartum mental health categories based on demographic and symptom-related features.

### Techniques

- Data Preprocessing
- Feature Engineering
- Missing Value Handling
- SMOTE / Data Balancing
- Stratified Cross-Validation
- Model Evaluation

### Models

- KNN
- SVM
- Random Forest
- XGBoost
- Stacking Ensemble

### Tools

**Python · Pandas · NumPy · Scikit-learn · XGBoost · Matplotlib**

### Techniques

- Data Preprocessing

- Feature Engineering
- Data Balancing
